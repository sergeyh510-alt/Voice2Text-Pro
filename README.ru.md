## 📱 О проекте

Voice2Text Pro — это мобильное приложение для Android, которое преобразует голос в текст и отправляет его на сервер через TCP-сокеты. Приложение разработано для быстрого голосового ввода текста в любые системы, поддерживающие протокол TCP.

## 🎯 
## Для кого это приложение
|Категория               |       	Применение |
|------------------------|-------------------|
Обычные пользователи|	                       Быстрый ввод текста голосом, отправка заметок на сервер, голосовое управление устройствами|
Разработчики|	                              Тестирование голосовых систем, создание голосовых интерфейсов, интеграция с другими проектами|

Люди с ограниченными возможностями|	         Удобный способ ввода текста без использования клавиатуры|

## 💡 
## Рекомендация

Приложение протестировано в связке с Windows-приложением DeepSeek_Voice_Bridge. Эта связка позволяет передавать голосовой ввод с мобильного устройства напрямую в среду Windows, обеспечивая голосовое управление локальными приложениями и сервисами.

## Протокол обмена
#### Протокол TCP-сокетов
|Байты	|Описание|
|--------|-----|
0–3|	Длина JSON-данных (big-endian, 4 байта)
4–N|	JSON-данные (в кодировке UTF-8)

### Формат JSON
```bash
{
  "text": "распознанный текст",
  "timestamp": 1234567890,
  "device": "Android"
}
```
### Пример пакета
[00 00 00 3A] [{"text":"Привет мир","timestamp":1712345678,"device":"Android"}]

### Пример сервера для тестирования (Python)
```bash
import socket

server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
server.bind(('0.0.0.0', 5000))
server.listen(1)

print("Ожидание подключения...")

while True:
    conn, addr = server.accept()
    print(f"Подключено: {addr}")
    
    # Читаем длину (4 байта)
    length_bytes = conn.recv(4)
    if not length_bytes:
        break
    
    length = int.from_bytes(length_bytes, 'big')
    print(f"Длина данных: {length} байт")
    
    # Читаем данные
    data = conn.recv(length)
    json_text = data.decode('utf-8')
    print(f"Получено: {json_text}")
    
    conn.close()
```

## Руководство пользователя

### Быстрый старт

    * Настройте сервер — введите IP-адрес и порт (например, http://192.168.1.100:5000)

    * Выберите режим — одиночный (SPEAK) или непрерывный (CONTINUOUS)

    * Настройте параметры — задержку, автоотправку, очистку

    * Нажмите SPEAK и начинайте говорить

    * Текст появится на экране → автоматически или вручную отправлен на сервер

### Подробное описание режимов
#### 🎤 
#### Одиночный режим (SPEAK)

  *  Нажмите кнопку SPEAK

  *  Произнесите одну фразу

  *  Приложение распознает и отобразит текст

  *  Подходит для коротких команд и отдельных фраз

Пример: Вы говорите "Включи свет" → текст появляется на экране    

### 🔄 
### Непрерывный режим (CONTINUOUS)

  *  Нажмите кнопку CONTINUOUS для запуска

  *  Приложение слушает постоянно

  *  Текст появляется по мере распознавания

  *  Нажмите CONTINUOUS повторно для остановки

  *  Идеально для лекций, диктовок, монологов

Пример: Вы читаете лекцию → приложение записывает всё, что вы говорите

## Настройки
|Параметр|	Описание|
|-------------|------------------------|
⏱️ Delay	|Задержка в секундах перед автоотправкой после окончания речи
🤖 Auto Send|	Включение/выключение автоматической отправки
🧹 Clear before Send|	Включено: каждый новый текст заменяет предыдущий. Выключено: тексты накапливаются с новой строки
🌐 Server	|Адрес сервера для отправки данных

### Сохранение настроек

#### Все настройки сохраняются автоматически при:

  *  Нажатии кнопки SAVE SETTINGS

  *  Выходе из приложения

  *  Потере фокуса полями ввода
